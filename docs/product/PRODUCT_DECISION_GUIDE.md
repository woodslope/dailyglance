# DailyGlance 产品决策指南

本文只定义右侧结论和展示语义。`getNoviceDecisionSummary()` 只能翻译既有 `meta`、`decision`、风险与信号状态，不得改变 `position`、`bsMark`、信号或积分；生产策略以 `docs/strategy/STRATEGY_DECISION_RULES.md` 为准。

真实改变仓位或 `B/S` 语义时，右侧结论必须与固定决策做快照样本联动校验，确认状态、动作、仓位、原因和失效条件仍在翻译同一份生产决策。

## 特殊行情状态展示规范

A 股行情源可能把临时交易状态写进股票名称，例如：

- `XD`：除息日。
- `XR`：除权日。
- `DR`：除权除息日。

这些前缀属于行情状态，不是股票长期名称。DailyGlance 面向新手时必须把“股票是谁”和“今天有什么特殊状态”分开处理：

1. 搜索建议、左侧自选股名称、固定样本名称统一展示规范股票名，不展示 `XD/XR/DR` 前缀。
2. 内置样本股票优先使用 `STOCK_DATABASE` 的固定全称，例如 `600519` 始终显示“贵州茅台”。
3. 非内置股票可去掉 `XD/XR/DR` 临时前缀后展示原名称；如果后续需要提示除权除息，应另设状态提示，不写进股票名。
4. 该规范只属于展示/命名层，不得改变行情价格、K 线、复权处理、策略结论、`position`、主图 `B/S` 或 `SIGNAL_VERSION`。

除非另有明确需求和复权数据验证，不新增除权除息分析模块；不要把这条名称规范扩展成分红解释、复权修正或价格跳空归因功能。

## 右侧决策面板话术规范

右侧面板面向新手，只保留“结论 -> 关键推导依据”两层信息，不把技术词当作结论，也不在主界面展开策略研究细节。原始信号、积分、仓位计算链和参数解释统一放到独立策略页。

个股与大盘共用信号、积分、风险、仓位和 `B/S` 决策链，但必须使用不同的展示语义：

- 个股回答“这只股票现在怎么买、怎么拿、怎么防守”，使用买入、持仓、减仓、离场和策略参考仓位等表达。
- 大盘/指数回答“当前市场是否适合增加、维持或降低风险暴露”，使用指数动能、风险仓位、市场风险和核心市场环境等表达。
- 大盘结论不得出现“个股信号”“买入依据”“持仓依据”或“再按个股信号考虑开仓”等个股话术；个股结论也不得把自身动作泛化成整个市场的风险暴露建议。
- 这只是展示翻译分流，不得复制策略计算、改变最终 `position` / `bsMark`，或创建第二套指数策略。

- 结论回答“现在怎么办”：状态、动作、仓位、为什么这么做、为什么是当前仓位，以及接下来什么变化会加仓、减仓或离场。
- 推导依据回答“为什么”：门禁、个股/指数有效信号、风险防守三项事实各解释一个维度。
- 策略研究细节不在主界面重复展示，统一通过设置里的“独立策略页”查看，页面直接读取生产策略配置。

每日结论区固定表达：

1. 状态：说明当前处境，例如“破位防守”“趋势转强”“离场冷静期”。
2. 动作：说明今天该做什么，例如“空仓观望”“只适合轻仓”“继续持有”“降低仓位”。
3. 仓位：股票显示策略参考仓位，指数显示当前风险仓位百分比。
4. 为什么这么做：买入、加仓、持有、减仓或离场时，先写真实驱动信号及发生时间，再说明这些条件带来的动作。积分结果不能替代原因。
5. 为什么是 X%：必须交代基础仓位、风险调整、固定仓位档位、市场新增风险限制或结构防守中真正生效的因素；仓位不变时也要写明仍由什么信号支持，以及为什么没有跨入更高或更低档位。
6. 接下来关注：同时写清向上和向下条件，例如“买入积分重新达到 X/X 后才考虑开仓；若跌破防守位或出现离场信号，继续空仓/降仓”。

结论三行标签固定为“为什么这么做”“为什么是 X%（指数为为什么是当前仓位）”“接下来关注”。兼容字段可继续保留，但页面不得再显示“结论原因、仓位结果、失效条件”等旧标签。

每一行只回答一个问题：第一行写真实触发原因和当前动作，第二行写基础仓位、实际生效的风险/市场限制与最终仓位，第三行同时写向上恢复条件和向下防守条件。避免重复抄写卡片顶部的动作与仓位，也不要把冷静期进度、积分、仓位变化和防守条件全部挤进同一个长句。常规结论每行以桌面卡片内约 2—4 行为宜；复杂强离场、冷静期或结构防守可适当增加，但必须保留完整条件，不做机械截断。

动作状态至少覆盖七类：空仓、首次建仓、加仓、持仓、减仓、离场、冷静期。每一类都必须得到非空的三行结论；波段个股另覆盖 `B11` 结构防守，指数使用“风险仓位/风险暴露”语义，不得混入“个股、试探仓”等措辞。

离场与冷静期必须区分展示：买入积分不足导致试探仓退出时，状态写“信号失效”，不得泛化成“破位防守”；真实强离场时说明下一交易日起进入冷静期，并显示当前计数、剩余交易日和重新计时。上述内容只解释既有决策，不得改变离场信号、积分、仓位或 `B/S`。

结论只展示实际参与积分的前 1-2 个关键原因，不显示 `B/L/W` 代码，不罗列完整指标，也不直接展示风险系数、门禁等内部计算词。必须区分“今日出现”和“最近几个交易日仍有效”；观察信号、被过滤信号和同组去重后未计分的信号不得写成买入原因。

最近几个交易日内的积分信号发生日期与当前所选日期不一致时，结论必须写成“YYYY-MM-DD 出现……，目前仍有效”，不得误写成“今日出现”，也不得让用户误读为主图 `B` 当天出现。展示策略提供的触发、有效与失效状态；旧实例失效后不得写成当前有效买入原因。

KDJ 金叉等历史信号在每日结论中只保留“发生日期、信号名称、目前是否有效”这项关键原因；“并非所选日当天、当前 K/D 关系、历史窗口仍保留几分”等补充解释统一放入独立策略页，不在主结论中重复展开。

股票模式的波段 `B11` 是唯一结构防守展示例外：局部回踩失守但结构未破时，结论写“结构未破 / 只适合轻仓”，说明暂停加仓并维持现有试探仓；防守位、失效条件和风控依据统一展示结构防守位，策略细节转入独立策略页。其他策略和信号不使用这一例外。

波段冲高回落事件必须展示实际执行时点：风险日已经降档时，状态写“冲高回落止盈”，动作写“降低仓位”或“离场观察”，并明确是当日实时分档止盈；不得写成“当日不卖出”或“等后续跌破再卖”。事件后局部锁定时，说明只是防止该标的旧积分立即回补；风险解除后则说明首次最多恢复 `30%` 和低仓观察期。

波段个股因风险评分低于 `40` 从 `30%` 降至 `0%` 时，状态写“极端风险防守”，原因必须列出事件日期和实际风险评分，并说明“事件前旧积分仍展示，但不参与重新建仓”。恢复观察期展示事件后新积分进度，不得只写“风险已恢复”；新积分独立达到 `3` 并完成价格/结构确认，或恢复完整上涨均线结构时，才写“风险解除”并首次恢复最多 `30%`。新 `B6/B11` 接管尚无仓位的已解除事件时，状态写“分步恢复”，当日不展示“趋势修复加仓”或直接提高到 `50%`。

波段首次建仓后两日内的压力位冲高失败使用独立文案：状态写“新仓失败离场”。原因不能只写“冲击压力位失败”，必须列出事件日期、高点、实际压力类型与价格、收盘价、买入日期与买入收盘价，以及上影占全天振幅的比例；例如“2026-07-24 高点3.57触及MA20 3.58，随后回落至3.40并收在全天最低；较2026-07-23买入收盘3.53下跌3.7%，上影占全天振幅52.9%”。下降 `MA20` 回落分支即使仍高于买入日收盘也可触发，原因必须改写为“形成长上影且收盘重新落回MA20下方”，不得误写“收盘不高于买入日收盘”；若收盘仍站在 `MA20` 上方，则保留 `30%`，不得显示新仓失败离场。第二个交易日触发时还必须说明是首次进入另一处新压力区，或列出最高价较前一日继续提高的比例；前一日已经进入同一压力区、当日最高价提高不足 `1%` 时，不得写“再次触及高点”或生成新仓失败离场。若收盘跌破买入日最低价，则明确列出收盘价和买入日最低价并说明“新仓硬失效”；盘中跌破后收回的弱势阴线，应列出盘中最低、买入日低点、收盘距防守位比例和阴线实体占振幅比例。上述文案只翻译既有决策，两者都不得写成已有成熟浮盈后的“止盈”；`B11` 局部位失守但结构位未破时，仍使用前述双层结构防守语义。

新仓普通压力失败或贴近防守位下跌失败完成一个完整交易日观察后，若事件后新买入积分达到 `4/4` 且来自至少两个独立计分组，同时风险、市场和离场检查通过，状态写“风险解除”，动作写“轻仓建仓”。原因必须说明“事件后新积分”和独立计分组数，并明确本次不要求先收复风险日收盘价；事件前旧积分、单一新信号和观察期内信号仍只写“风险恢复观察”。首次恢复最多 `30%`，随后进入一个交易日低仓观察。下降 `MA20` 回落分支不使用该通道，仍需先完成价格恢复。

波段首次试探仓在建仓后两日内，因收盘跌破买入日最低价触发新仓硬失效后，若完整观察期已结束，事件后新积分独立达到正常建仓门槛且至少来自两个计分组，同时风险和市场上限允许 `30%` 且无离场、预警或冷静期时，状态写“风险解除”，动作写“轻仓建仓”。原因列出事件后新积分与独立计分组数，不得误写成价格已站回失效位；事件前旧积分、单一新信号或次日信号仍只写“风险恢复观察”。该通道不用于普通买入信号硬失效。

波段指数首次提高风险后的两日内，盘中跌破买入日最低价、收盘虽收回但仍满足指数弱收阴线条件时，若风险仓位归零，状态写“指数新仓失败离场”，动作写“保持低风险暴露”；若只降低一档，状态写“指数新仓下跌防守”，动作写“降低风险暴露”。原因必须明确说明“盘中跌破买入日最低价、收盘虽收回但仍是贴近防守位的弱势阴线”，不得等到下一交易日硬失效后再把这根 K 线解释为卖点。该文案只翻译波段指数决策，不套用到其他策略。

波段个股的买入积分仅因窗口到期而清零，但买点防守位未破、`MA20` 未下行且 MACD 柱仍为正时，状态写“到期防守观察”，动作写“轻仓观察”，并说明本次不生成 `S`。若同时保持 `MA20 > MA60`、`MA20` 不低于五个交易日前，并进入最多两日的扩展观察，状态改写“趋势洗盘观察”；原因说明“积分到期不等于上涨结构失效”，不得写成新买点。接下来关注必须写明需重新站上 `MA5/MA20` 或出现新的有效买入信号；普通观察一日、趋势洗盘最多两日，到期仍未接管，或均线结构/原买点防守位失效时，状态写“到期观察结束”并如实显示离场。该语义只翻译既有决策，不用于指数。

波段个股已有 `30%` 持仓且当日新触发 `B6 缩量回踩不破`，收盘回到 `MA20` 上方、`MA20` 未下行，并最终允许提高到 `50%` 时，状态写“趋势修复加仓”，动作写“提高仓位”。原因必须明确写“今日缩量回踩20日线后收回”，不得泛化为“重新站回20日线”；仓位说明同时写明本次 `B6` 只负责 `30% -> 50%`，`80%` 仍需积分正式达标和完整多头资格。若没有当日新 `B6`，趋势抱单只维持原仓；若风险或市场上限阻止增仓，不得展示“趋势修复加仓”。该语义不用于指数和其他三套策略，也不生成新的 `B/S`。

波段个股前一日为“到期防守观察”，下一交易日新触发 `B11`、收盘重新站上 `MA5/MA20` 且 `MA20` 未下行，并最终允许由 `30%` 提高到 `50%` 时，状态写“防守接管加仓”，动作写“提高仓位”。原因说明观察成功、新 `B11` 与均线恢复共同触发；仓位说明必须写清“30%基础仓＋20%波段仓”，以及弱市30%上限只对此事件窄放宽，不代表取消市场门禁。波段仓继续有效时可写“波段仓持有”；额外20%先退出而基础仓仍有效时写“波段仓减仓”，明确 `50% -> 30%` 不生成 `S`。基础仓真实失效时仍按原规则离场。该语义不用于普通 `B11`、空仓建仓、指数或其他三套策略。

波段个股已有 `30%` 持仓，收盘仅小幅低于抬升中的 `MA20`，同时留下明显下影、结构防守位未破，并由生产决策进入单日防守观察时，状态写“MA20回踩观察”，动作写“轻仓观察”。原因必须明确写“本次不满足B6，因此不加仓；但下探收回且结构未破，也不机械清仓”，仓位说明写“保留30%一日且不生成S”。接下来关注必须写明下一交易日需重新站回 `MA20`，或新触发 `B6/B11` 接管；若未接管、收盘跌破观察日低点或结构防守位，则离场。观察到期未接管时，状态写“MA20观察结束”并如实显示 `S`。该展示不得把普通阴线翻译成回踩确认，不得把观察形态改写成 `B6`，也不用于指数和其他三套策略。

波段抄底型个股的窄幅趋势防守例外必须单独展示：完整多头中的单独 `L3` 状态写“MA20趋势防守”，原因写“单独 MACD 死叉，价格仍在完整多头结构中，本日保留 30% 观察”；买点失效位虽被收盘跌破但仍守住 `MA20` 时，状态写“MA20回踩防守”，原因写“买点失效位虽被收盘跌破，但价格仍守住 MA20，先保留 30% 观察”。两者都必须明确下一交易日需重新站回 `MA20` 或出现新的 `B6/B11`，否则清仓；不得写成“清仓离场”、恢复旧积分或生成新的 `B`。该例外不用于 `L3+L4/L9/L10`、明显结构破位、风险归零、指数或其他策略。

发生失效转换时，结论必须说明信号名称、失效原因、积分变化和仓位动作；独立策略页可进一步保留信号发生日、失效日和“不计分”状态，不得再把失效信号写成当前有效买入原因。

关键推导依据固定翻译：

- 核心建仓门禁：只限制增加风险。核心宽基偏弱时，普通机会新增风险上限为30%，标的自身独立走强上限为50%；核心宽基偏弱不等于所有标的弱，已有仓位不因市场标签被动强减，硬风控、强离场和冷静期始终优先。具体门禁计算以策略规则为准。
- 指数动能 / 个股信号：买入时展示“买入依据”，持仓时展示“持仓依据”，未买入时展示“未买入原因”；同时说明实际计分信号、今日/近窗来源和积分阈值。
- 风控/防守：展示当前风险依据、防守位和真实离场/预警信息，不重复结论区的动作口号；B11 局部回踩失守时，以结构防守位替代通用止损位，避免出现两条冲突的退出价格。

### 个股两层内容

- 结论：显示“个股每日结论”，回答买入、持仓、减仓或离场，仓位称为“策略参考仓位”。
- 推导依据：固定为“核心建仓门禁、个股信号、风控/防守”。门禁是外部约束，只有真实限制本次新仓或加仓时才强调限制。
- 策略细节：通过独立策略页查看仓位档位、信号入口、积分窗口、风险限制和完整配置。股票只有在 `收盘价 > MA20 > MA60` 且 `MA20` 不下降时才可使用 `80%`；中期下降结构上限为 `30%`，修复中或数据不完整时上限为 `50%`。

### 大盘/指数两层内容

- 结论：显示“大盘每日结论”，回答增加、维持或降低风险暴露，仓位称为“当前风险仓位”。
- 推导依据：固定为“核心市场环境、指数自身动能、市场风险/防守”。核心宽基状态是市场背景，当前指数仍按自身动能和风险形成结论。
- 策略细节：通过独立策略页查看风险仓位档位、指数信号入口、积分窗口、风险限制和完整配置，风险限制称为指数高风险上限。
- 核心宽基偏弱时，大盘和个股均说明策略给出的新增风险上限；已有仓位不因市场标签被覆盖，硬风控仍可直接降仓或清仓。

## 展示边界

展示改动应让用户看懂状态、动作、仓位、理由、风险和失效条件；不把观察信号写成买卖指令，不承诺收益，也不新增第二套策略判断。只改展示时，不改变生产策略的最终仓位或主图 `B/S`。
